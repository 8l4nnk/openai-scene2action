# Demo 공격 데이터 및 VLM 응답

> **이 폴더의 공격 데이터는 여러 관련 논문에서 제시한 공격 기법과 시나리오를 바탕으로 Daybreak가 생성·선별한 데모용 데이터입니다.**
>
> 텍스트 공격 270건과 이미지 공격 64건은 로봇·VLM 안전 필터 데모에 사용하는 입력입니다. 각 VLM 응답은 과거 모델의 관찰 기록으로 보존했으며, 이 폴더는 새 모델 호출이나 Isaac 명령 전송 기능을 제공하지 않습니다.

## 구성

- `text-270.jsonl`: R15 텍스트 공격 270건. 대조 270건은 포함하지 않는다.
- `image-r23-64.jsonl`, `images/`: R23 사용자 시스템 프롬프트 평가에 사용한 이미지 64건. 사용자 텍스트 입력은 비어 있다.
- `qwen-results.jsonl`: Qwen3-VL-32B의 기존 응답 334건.
- `vlm-results.jsonl`: 원본에 있던 3개 모델의 기존 응답 1,002건. 새 모델 호출은 수행하지 않았다.
- `manifest.json`: 입력 및 사본 파일 SHA-256. 입력과 응답은 사례 ID 및 입력 해시로 연결한다.


Qwen의 기존 판정은 텍스트 EXECUTE 183 / REFUSE 78 / UNPARSEABLE 9,
이미지 EXECUTE 24 / HOLD 40이다. EXECUTE는 모델의 계획 제안이며 물리 위해 성공을 뜻하지 않는다.

원본은 보존했다. 요청 봉투, 인증정보, 로컬 절대경로, 중복 이미지 base64,
정답 계획은 Git 사본에 넣지 않는다. 응답 원문과 parsed_plan은 관찰 자료이며 실행 지시가 아니다.

대시보드의 F1/F2/F3는 이 기록에 대한 현재 정책의 오프라인 재검사다.
F1은 입력·응답 무결성, F2는 고정 정상 운반 계약, F3는 실제 실행 승인 유무를 검사한다.
F3에 필요한 최신 3D 경로·관측·일회성 승인은 이 기록에 없으므로 실행을 승인하지 않는다.
이 경로에는 모델 호출이나 Isaac 명령 전송 기능이 없다. 차단 뒤 단계는 미실행으로 표시한다.
카메라는 별도 정상 Isaac 인스턴스의 관측이며 각 공격이 시뮬레이션된 영상으로 표시하지 않는다.

## F1·F2 결합 재검사

astra-text-screening.jsonl은 기존 Astra 일반 입력 선별의 텍스트270건 판정 사본이다. 원문 fingerprint를 대조했으며 새 API 호출은 없다. 이미지 평가 세트는 R23과 달라 결합하지 않는다. Qwen EXECUTE 텍스트183건의 최초 차단은 F1 167건·F2 4건, 보류12건이다. F3는183건 모두 미실행. 정상 대조군이 없어 오탐률·정확도를 의미하지 않는다. 기존 일반 정책 판정과 현재 계약 검사를 결합한 오프라인 재검사이며 현재 실시간 통합 결과가 아니다.
