# 로컬 시뮬레이터 검증 기록

## 범위

2026-10-09, Windows 11 / Python 3.12.10에서 로컬 2D 시뮬레이터를 검증했다. 실물 로봇과 AWS 리소스는 사용하지 않았으며, 시뮬레이터의 OpenAI 계획 생성 API는 호출하지 않았다. 해당 요청 구조는 오프라인 전송 대역으로 검사했다. 이후 추가한 OpenRouter 코퍼스 실험은 별도 [데이터 평가 기록](corpus-validation-2026-10-09.md)에 정리했다.

## 자동 검증

- `.venv/Scripts/python.exe -m pytest -q --basetemp=.data/tests-13 --tb=short`: 50 passed.
- `node --check scene2action/static/app.js`: 구문 검사 성공.
- Starlette TestClient가 httpx 사용에 대해 deprecation warning 1개를 출력했다. 테스트 실패는 아니다.
- Windows 샌드박스의 기본 임시 경로 권한 문제와 asyncio 내부 socketpair 초기화 제한을 확인했다. 작업 폴더 내 임시 디렉터리와 로컬 소켓을 허용한 실행으로 검증했다.

검증 항목: 두 정상 계약 완료, 잘못된 대상·목적지·순서·Adapter 변환 차단, IMAGE 모드의 텍스트 배제, 실모델 설정 누락 HOLD, 승인 만료, 중복 실행 거부, 정지 후 재실행 거부, 중간 경로와 여유 반경 충돌, 실행 중 장애물·센서 단절 정지, 재시작·초기화 무효화, planner 실패, NaN·무한대 거부, 재관측, 계획 중 정지, 기록 저장 실패, HTTP Host/Origin/크기·필드 검증.

## 브라우저 확인

- 실제 로컬 서버에서 정상 TEXT 계획을 평가하고 8개 명령을 통해 완료하는 흐름을 확인했다.
- IMAGE 모드에서 텍스트 입력이 숨겨지고 서버 카메라 영상이 표시되는 것을 확인했다.
- IMAGE + 목적지 불일치 시나리오에서 F2 BLOCK과 실행 버튼 비활성화를 확인했다.
- 실행 중 장애물을 추가했을 때 STOP 이벤트와 정지 상태를 확인했다.
- 확인 시점 브라우저 console error/warn은 없었다.
- 좁은 viewport에서 문서 너비와 scrollWidth가 일치하고 단일 열 레이아웃으로 변하는 것을 확인했다.
- 센서 단절 직후 대기 승인이 STOPPED와 APPROVAL_REVOKED로 바뀌며 실행 버튼이 비활성화되는 것을 확인했다.
- 과거 BLOCKED 기록을 보는 동안 현재 실행 상태는 RUNNING, 장면 경로는 현재 run으로 유지되는 것을 확인했다.

## 독립 리뷰

`/root/review_local_simulator`를 `model="gpt-6-luna"`, `reasoning_effort="max"`, `fork_turns="none"`으로 생성했다. 읽기 전용으로 코드·테스트·설정·UI와 관련 호출 경로를 검토했다.

초기 리뷰의 P1 센서 단절 직후 실행 허용, P2 폐기된 대기 승인 기록, P2 과거 기록과 라이브 상태 혼동을 모두 수정했다. 회귀 테스트 4건이 수정 전 실패하고 수정 후 통과했다. 같은 리뷰어의 재검토 결과는 지적 사항 없음이다. 이후 모델 입력 필터와 코퍼스 도구 추가분은 별도 추가 리뷰 대상이다.

추가 리뷰에서 P2 두 건(입력 필터 대기 중 정지 후 후속 planner 요청, JSONL 파싱·manifest 해시의 서로 다른 읽기)을 확인했다. 두 경계를 회귀 테스트로 재현한 뒤 후속 요청 전 상태 재검사와 동일 바이트 스냅샷 파싱·해시로 수정했다. 전체 50개 테스트가 통과했다. 같은 리뷰어가 영향 회귀 테스트 2개를 별도 임시 경로에서 실행해 통과를 확인했으며, 최종 재검토 판정은 지적 사항 없음이다.

## 합성 평가 벤치마크

Qwen3-VL-32B 호환성 후속 검증: 미지원 reasoning 옵션을 생략하는 회귀 테스트를 추가해 수정 전 실패를 확인했고, 수정 후 전체 **52개 테스트**가 통과했다(기존 Starlette 경고 1건). `/root/review_local_simulator` (`gpt-6-luna` / `max`)가 guard.py·test_guard.py와 관련 호출 경로를 재검토해 지적 사항 없음으로 판정했다. 리뷰어는 guard 테스트 12개를 독립 실행해 통과를 확인했다. 외부 실모델 평가 결과는 [별도 기록](corpus-validation-2026-10-09.md)에 구분했다.

명령: `python -m scene2action.benchmark --samples 30`

`Engine.evaluate` 호출 전체와 SQLite 저장을 포함한다. HTTP 전달, 실모델 추론, 물리 제어·제동은 제외한다. 엔진 계산 시간만 표시하는 화면 수치와 측정 범위가 다르다.

| 계약 | 입력 | 표본 | p50 ms | p95 ms | p99 / 관측 최대 ms |
|---|---|---:|---:|---:|---:|
| sort | TEXT | 30 | 3.710 | 4.460 | 4.514 |
| sort | IMAGE | 30 | 15.739 | 20.024 | 59.735 |
| sort | IMAGE_TEXT | 30 | 14.788 | 17.053 | 17.397 |
| kit | TEXT | 30 | 3.307 | 3.826 | 3.846 |
| kit | IMAGE | 30 | 14.832 | 18.316 | 19.407 |
| kit | IMAGE_TEXT | 30 | 18.375 | 22.559 | 22.862 |

표본 30개의 nearest-rank p99는 관측 최대와 같다. 결과는 이 환경의 한 번의 표본이며 SLA, 방어 정확도, 실시간성 또는 판매 준비 완료를 의미하지 않는다.

## 범위 차이

- OPA 등 외부 런타임 전체 통합 대신 교체 가능한 로컬 계약 검사기로 첫 실행 경로를 완성했다.
- 공통 지원 행동은 순서가 정해진 물체 이송이다. 임의 공정과 장비에 대한 범용성은 추가 검증이 필요하다.
- 운영 배포, 3D/물리 안전, 실모델 품질 검증과 고객 파일럿은 후속 범위다.
