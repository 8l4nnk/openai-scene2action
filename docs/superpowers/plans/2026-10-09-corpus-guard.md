# 기존 데이터와 모델 기반 입력 필터

사용자 추가 요청: 이성민 산출물의 XLSX/JSONL, 기존 Runpod 환경, OpenRouter Opus 5.5와 기존 Pod의 Qwen을 방어 필터 구축에 활용한다. 개발/리뷰는 Codex만 사용하며 외부 모델은 요청된 평가 대상으로만 호출한다.

- 원본 JSONL을 읽기 전용으로 읽고 파일·입력 해시, 라벨, 모드를 보존한다. 이미지 파일은 지정한 데이터 루트 안에서만 읽는다. 동일 입력 중복을 식별한다.
- 모델 입력에는 텍스트/이미지만 보낸다. 정답·공격 분류·기존 결과를 전달하지 않는다. IMAGE에는 사용자 텍스트를 추가하지 않는다.
- 모델 필터는 PASS/BLOCK/HOLD와 고정 범주만 반환한다. 어떤 동작 명령도 생성·전달하지 않는다. 실패·잘못된 응답은 HOLD로 기록한다.
- 모델 필터는 검증용 CLI에서 먼저 측정한다. 기존 정상 작업 계약과 다른 코퍼스의 대조 라벨을 바로 실행 승인이나 방어 정확도로 해석하지 않는다.
- 공급자 실패율, 라벨별 PASS/BLOCK/HOLD, 표본 수, p50/p95/p99, 모델 ID와 정책 해시를 기록한다. 오탐률로 사용하려면 정상 작업 매핑과 라벨 검수가 필요하다.
- 먼저 제한된 표본에서 연결·형식을 검증한다. Runpod의 실제 모델/환경을 확인하고 같은 입력·정책 조건으로 비교한다. 실물 로봇과 공격 실행은 연결하지 않는다.
- 단위/회귀 테스트 후 gpt-6-luna/max 읽기 전용 독립 리뷰를 요청한다.
