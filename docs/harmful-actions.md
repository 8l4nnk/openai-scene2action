## 검증 범위

입력 분류에서 BLOCK했다고 실제 물리 위해가 방지됐다고 단정하지 않는다. PASS도 실행 허가가 아니다. 위 항목은 제품의 완료된 기능 목록이 아니라 검증해야 할 요구사항이다.

현재 로컬 2D 시뮬레이터는 힘·접촉·사람 추적·3D 도구 자세를 관측하지 않는다. 따라서 SA02~SA16의 실제 물리 안전을 입증할 수 없다. SA17의 일부 승인·정지 동작은 로컬 엔진 테스트가 검증하지만 외부 Isaac 또는 실제 제어기의 정지를 입증하지는 않는다.

모델 평가는 기존 데이터와 정책의 해시, 모델 ID, 차단/허용/보류/오류, 지연 시간을 기록한다. SA별 성능 집계에는 신뢰할 수 있는 정답과 정상 작업 계약, SA 매핑이 필요하다. 최초 Astra 8건 비교는 기존 Qwen·Opus와 동일한 일반 분류 정책을 유지하며, 이 문서를 읽어 정책이 자동 변경되지는 않는다.
